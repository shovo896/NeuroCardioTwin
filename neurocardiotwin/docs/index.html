PUBLIC TECHNICAL BRIEF · RESEARCH PROTOTYPE

Secure, evidence-grounded brain–heart AI.

NeuroCardioTwin is an AI-native research decision-support workflow for validated EEG and ECG time-series analysis. It separates biomedical inference from language generation, protects private data, and supports English, Bangla, and Banglish interaction.

THE SOLUTION

One responsible workflow, from signal to explanation.

Users upload or enter numerical signals; the backend validates them before the appropriate local model runs. The explanation layer can only receive compact model metadata and approved research evidence—not raw waveform data.

01

Validate input

Check numeric values, sampling rate, signal length and model compatibility.

02

Infer locally

Run the selected ONNX checkpoint through ONNX Runtime on the backend.

03

Retrieve evidence

Retrieve relevant approved knowledge using semantic vector search.

04

Explain safely

Present a grounded research explanation in the user’s selected language.

IDENTITY & ACCESS

Auth0 OAuth 2.0 + OIDC

Auth0 verifies identity and issues scoped access tokens. The backend validates JWT signature, issuer, audience and expiry before protected workspace, profile, history, decision-support or MCP access.

PRIVATE DATA

Supabase + Row Level Security

Profile preferences and analysis metadata are stored server-side. Row Level Security and server-side identity filtering prevent one user from reading another user’s private records.

BIOMEDICAL MODEL LAYER

Three purpose-specific ONNX model paths.

The language model does not generate biomedical predictions. Local ONNX checkpoints produce model outputs; RAG supports their research interpretation.

EEG seizure-pattern detection

Input: validated EEG time window
Output: pattern probability, threshold comparison and detected windows when present.

ECG arrhythmia classification

Input: validated ECG time window
Output: rhythm class, confidence and model-specific markers.

ECG–EEG forecasting

Input: paired validated ECG and EEG windows
Output: next-window forecast, error metrics and trajectory views when available.

Research boundary: NeuroCardioTwin is a research-support prototype, not a medical device and not a replacement for clinical diagnosis, triage or treatment.

RAG-GROUNDED DECISION SUPPORT

Evidence is retrieved before language is generated.

1

Minimal metadata

Only analysis type, model label, confidence, threshold, validation status and session label are compacted.

2

Semantic retrieval

Hugging Face creates embeddings; Pinecone retrieves the top relevant approved knowledge excerpts by cosine similarity.

3

Bounded explanation

Qwen receives the local result plus retrieved evidence to give a concise, grounded explanation with safe next steps.

Privacy boundary

Raw EEG/ECG arrays, uploads, email addresses, Auth0 identifiers and access tokens are excluded from vector retrieval, prompts and decision history. The LLM explains model output; it never receives the patient waveform.

TRUST, ACCESSIBILITY & SAFETY

Designed for understandable and responsible research use.

Multilingual interaction

English, Bangla, Banglish and additional chat languages reduce access barriers for diverse users.

Fail-closed access

Protected APIs and MCP services require verified Auth0 bearer tokens; unavailable services do not expose private data.

Urgent-symptom guidance

For emergency warning signs, the interface prioritizes immediate help guidance and displays Bangladesh emergency service 999.

INTEGRATION SURFACE

Protected APIs and least-privilege MCP services.

Browser authentication and the project’s independent Python verifier both exercise the same protected MCP contracts. No MCP tool returns raw physiological signals.
